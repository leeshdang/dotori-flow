Standalone Deployment Guide

Dotori Flow 독립 환경 구축 매뉴얼

다른 사용자의 환경에 전혀 영향을 받지 않고, 오직 나만의 GitHub과 Vercel 주소를 통해 완전히 격리된 이슈 관리(Jira 스타일) 시스템을 5분 만에 무료로 구축하는 가이드입니다.

🔒
완벽한 데이터 격리 (100% 독립)
본인이 개설한 Vercel 도메인과 로컬 스토리지를 사용하므로 타인의 데이터나 설정에 절대 간섭하지 않습니다.
💰
평생 무료 호스팅 (비용 0원)
Vercel Hobby 플랜(0원) 및 GitHub Free 계정을 활용하므로 신용카드 등록 없이 영구 무료로 서비스됩니다.
⚙️
자율적인 필수 필드 설정
관리자가 비즈니스에 필요한 커스텀 필드와 Mandatory(필수 입력) 조건을 자유롭게 커스터마이징합니다.

공유해야 할 핵심 파일 목록 및 준비물
소요시간: 1분

📦 사용자에게 공유해야 하는 파일 묶음

전달받은 사용자에게는 아래 파일들이 포함된 Dotori_Flow_Starter_Kit.zip 압축 파일(또는 GitHub 소스)만 전달하면 됩니다:

파일 / 디렉토리 역할 설명
src/ 핵심 소스코드 칸반 보드, 이슈 폼, 관리자 필드 설정 콘솔, 보안 유틸리티 전체
public/ 정적 에셋 & 라우트 파비콘 및 Vercel/Netlify 리다이렉트 규칙 (_redirects)
index.html 웹페이지 루트 웹 애플리케이션 진입점 및 폰트 로더
package.json 프로젝트 명세서 React, Vite, Lucide 아이콘 등 필수 오픈소스 의존성 명세
vite.config.js 빌드 엔진 설정 초고속 Vite 번들러 환경 설정
vercel.json Vercel 배포 설정 SPA 라우팅 시 404 에러를 방지하는 리라이트 규칙
💡
제외 대상 (공유할 필요 없는 파일):
node_modules/ (의존성 폴더), dist/ (임시 빌드물), .git/ (기존 Git 기록)은 용량만 크고 환경 충돌을 유발하므로 공유하지 않는 것이 원칙입니다. 이미 Dotori_Flow_Starter_Kit.zip에 필요한 순수 파일만 엄선되어 있습니다.
1
나만의 GitHub 저장소(Repository) 만들기
소요시간: 2분

나만의 독립된 프로젝트를 구축하기 위해, 내 개인 GitHub 계정에 새 저장소를 생성합니다.

방법 A: 웹 브라우저에서 직접 올리기 (초보자 추천)

  1. GitHub.com에 로그인합니다. (계정이 없으면 무료 회원가입)
  2. 우측 상단의 + 버튼을 누르고 New repository를 클릭합니다.
  3. Repository name에 원하는 이름(예: my-dotori-flow)을 입력하고, Public 또는 Private을 선택한 뒤 맨 아래 Create repository를 클릭합니다.
  4. 새로 만들어진 저장소 화면에서 uploading an existing file 링크를 클릭합니다.
  5. 다운로드받은 Dotori_Flow_Starter_Kit.zip 압축을 푼 폴더 안의 파일들(src, public, index.html 등)을 마우스로 드래그하여 올린 후, 아래 Commit changes 초록색 버튼을 누르면 끝납니다!

방법 B: Git 터미널 명령어로 올리기 (개발자용)

# 1. 압축을 푼 폴더로 이동
cd my-dotori-flow

# 2. Git 초기화 및 커밋
git init
git add .
git commit -m "feat: My initial Dotori Flow instance"
git branch -M main

# 3. 내 GitHub 저장소 주소 연결 후 푸시
git remote add origin https://github.com/내아이디/my-dotori-flow.git
git push -u origin main
2
Vercel에서 나만의 웹 주소 무료 배포하기
소요시간: 2분

이제 Vercel과 내 GitHub 저장소를 연결하여 전 세계 어디서든 접속할 수 있는 나만의 고유 웹 주소(예: https://my-team-flow.vercel.app)를 발급받습니다.

  1. Vercel.com에 접속하여 Sign Up (또는 Log In)을 누르고, 반드시 Continue with GitHub로 로그인합니다.
  2. 🚨 가장 중요한 플랜 선택 (주의):
    가입 과정에서 플랜 선택 화면(Choose a Plan)이 나오면, 절대 유료인 Pro를 누르지 마시고 두 번째 항목인 I'm working on personal projects (Hobby)를 선택해 주세요.
    ⚠️
    Hobby 플랜은 평생 0원 완전 무료입니다! 신용카드 등록도 전혀 필요 없습니다.
  3. 대시보드 상단의 Add New... ➡️ Project를 클릭합니다.
  4. 방금 내 GitHub에 올린 my-dotori-flow 저장소 옆의 Import 버튼을 클릭합니다.
  5. 설정 화면 확인 (모두 자동 감지되므로 변경할 필요 없습니다):
    • Framework Preset: Vite
    • Build Command: npm run build
    • Output Directory: dist
  6. 맨 아래 파란색 Deploy 버튼을 클릭합니다!
🎉
배포 완료!
약 30초 후 폭죽 효과와 함께 https://my-dotori-flow-xxxx.vercel.app 형태의 나만의 인터넷 웹사이트 주소가 완성됩니다. 이제 이 주소로 누구에게나 공유할 수 있습니다!
3
나만의 관리자 비밀번호 변경 및 필수 필드 세팅
소요시간: 1분

배포된 웹사이트에 접속한 후, 보안을 위해 관리자 비밀번호를 바꾸고 우리 팀의 필수 입력 항목을 설정합니다.

1. 관리자 권한 로그인

  • 화면 오른쪽 상단의 [관리자 로그인 🔒] 버튼을 클릭합니다.
  • 초기 기본 비밀번호인 admin1234를 입력하고 엔터를 누릅니다.
  • 상단에 초록색 Admin 뱃지가 활성화됩니다.

2. 즉시 비밀번호 변경하기 (보안 필수!)

  • 우측 상단 Admin 뱃지 바로 옆에 있는 [🔑 비밀번호 변경] 버튼을 누릅니다.
  • 나만 아는 새로운 비밀번호(4자리 이상)를 입력하고 확인을 누르면 영구 변경됩니다.

3. 필수 입력 항목(Mandatory) 및 커스텀 필드 설정

  • 상단 탭에서 필드 관리 (Admin) 콘솔로 이동합니다.
  • Mandatory 스위치 토글: 팀원들이 티켓을 만들 때 반드시 입력해야 하는 항목(예: 담당자, 마감일, 설명 등)의 스위치를 켭니다.
  • 커스텀 필드 추가: 우측 상단 + 커스텀 필드 추가 버튼을 눌러 우리 회사/프로젝트에 필요한 필드(예: 배포 버전, 고객사명, 버그 재현 경로 등)를 자유롭게 추가할 수 있습니다.
🛡️
보안 강제 집행 엔진 탑재:
관리자가 필수로 지정한 항목은 티켓 생성 폼에서 빨간 별표(*) 및 필수 배지로 표시되며, 단 하나라도 빈칸이면 티켓 저장이 원천 차단됩니다.

자주 묻는 질문 (FAQ) & 문제 해결

Q. 내가 설치한 Dotori Flow가 원래 제작자나 다른 사람의 데이터와 섞일 위험이 있나요?

전혀 없습니다! 본 가이드를 통해 본인 계정의 GitHub과 Vercel에 독립적으로 배포했기 때문에, 웹사이트 도메인, 데이터 저장소, 관리자 비밀번호까지 100% 분리된 독립 인스턴스(Silo)로 구동됩니다.

Q. Vercel 배포 후 비용이 청구되나요?

비용은 0원입니다. 가입 시 선택한 Hobby 플랜은 개인 및 소규모 프로젝트를 위해 Vercel에서 무료로 제공하는 플랜입니다. 매월 수만 건 이상의 트래픽을 무료로 감당할 수 있습니다.

Q. 기능을 수정하거나 로고를 바꾸고 싶으면 어떻게 하나요?

내 GitHub 저장소에서 코드를 수정한 뒤 git push(또는 웹에서 수정 후 커밋)하면, Vercel이 30초 내에 자동으로 감지하여 전 세계에 실시간 반영해 줍니다.

Q. 페이지가 업데이트되지 않고 옛날 화면이 보일 때는 어떻게 하나요?

브라우저의 캐시 때문일 수 있습니다. 키보드의 Ctrl + F5 (Mac은 Cmd + Shift + R)를 눌러 강력 새로고침을 진행해 주세요.
