# 🌰 Dotori Flow (도토리 플로우) - 독립형 이슈 트래커

> **나만의 커스텀 필드와 필수(Mandatory) 입력 규칙을 자유롭게 설정하는 모던 이슈 트래킹 시스템**

Dotori Flow는 Atlassian Jira의 보편적인 칸반 보드 및 티켓 관리 UX를 모던한 웹 기술(React + Vite)로 구현한 독립형 이슈 관리 툴입니다.

---

## 🌟 주요 특징

1. **관리자 필수(Mandatory) 필드 동적 제어**:
   - 티켓 생성 시 필수로 입력받을 항목을 관리자가 원클릭 토글 스위치로 설정.
   - 필수 필드가 누락되면 티켓 생성이 원천 차단되며 안내 메시지 노출.
2. **커스텀 필드 무제한 생성**:
   - 텍스트, 장문(Textarea), 드롭다운(Select), 날짜(Date), 숫자(Number) 등 프로젝트 맞춤 필드 지원.
3. **역할 기반 접근 제어 (RBAC)**:
   - 일반 사용자(`Member`)와 관리자(`Admin`) 권한 분리.
   - 관리자 비밀번호 인증을 통해서만 필드 설정 콘솔 접근 가능 (기본 비밀번호: `admin1234`, 관리자가 직접 변경 가능).
4. **완벽한 데이터 격리 및 독립성**:
   - 타 사용자의 배포 환경이나 데이터에 일절 영향을 주지 않는 완전 독립 실행.

## 🚀 빠른 시작 (3분 배포 가이드)

### 방법 A: Vercel로 1클릭 무료 웹 호스팅 (추천)
1. GitHub에서 본 저장소를 포크(Fork)하거나 본인 GitHub에 새 저장소로 푸시합니다.
2. [Vercel](https://vercel.com)에 로그인 후 `Add New... -> Project`에서 해당 저장소를 선택합니다.
3. 플랜 선택 시 **`Hobby (개인/무료)`**를 선택합니다. (비용 0원 영구 무료)
4. `Deploy` 버튼을 누르면 1분 만에 `https://my-flow.vercel.app` 고유 주소가 생성됩니다!

### 방법 B: 내 컴퓨터 로컬에서 실행
```bash
# 1. 의존성 설치
npm install

# 2. 로컬 개발 서버 실행
npm run dev

# 3. 브라우저에서 http://localhost:5173 접속
```
